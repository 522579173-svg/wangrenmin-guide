🔑 API 设置 仅保存在本机浏览器
① Key 有两种保存方式：
安全模式（推荐）：部署到腾讯云 CloudBase 后，把 Key 填进云函数环境变量（DEEPSEEK_KEY / AMAP_KEY），前端代理地址已自动填入，浏览器里完全不出现 Key。
直连模式：把 Key 填在本页（仅存本机浏览器 localStorage，上传不会发送到任何服务器），适合本地体验。
② 高德 Key 注册：lbs.amap.com → 控制台 → 创建应用 → 添加“Web服务”Key（个人开发者免费）。
③ 真 GPS 需要 HTTPS：部署到 CloudBase（自带 https）后手机访问即可。
④ 本地双击 index.html 无定位权限，可用“模拟演示”体验完整流程。

🍎 安装到 iPhone 桌面

1
请确认当前使用的是 Safari 浏览器。如果在微信中，请点右上角“…”→“在Safari中打开”。
2
点 Safari 底部的 ⇧ 分享按钮（方框向上箭头）。

在菜单中向上滑，点 “添加到主屏幕”，然后点右上角“添加”。
安装后请从桌面“景点讲解”图标打开，定位和全屏体验更稳定。
